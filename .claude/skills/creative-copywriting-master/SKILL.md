## Carousel-specific architecture

- **Slide 1** — hook + one-line promise of what's inside. No setup, no "let's dive in."
- **Slide 2** — the problem, stated plainly. One idea only.
- **Slides 3 to N-1** — one point per slide. Label + 1-3 lines max. Never stack two ideas on one slide.
- **Last slide** — CTA. State exactly what to do ("Comment X") and exactly what they get in return.
- Every slide needs a slide number/progress marker if more than 4 slides — readers want to know how much is left.

## Platform differences

- **Instagram:** short lines, heavy line breaks, hook must work with zero context (no headline visible before tap). Caption can run long underneath — front-load the highest-value line.
- **X:** hook is the whole first line of the tweet, visible before any click. No line-break crutch — the sentence itself has to carry weight. Threads: each tweet should stand alone if quote-tweeted.
- **LinkedIn:** slightly more explanatory tone is acceptable, but the banned-word list still applies — LinkedIn is where AI-sounding corporate voice is most common, so it's the platform where cutting it stands out most.
